\chapter{Global Pragma Declarations\label{chap:Global Pragma Declarations}}

Pragmas are constructs present in the \untypedast{} that are designed to be used
by third-party tools.
They do not produce \typedast{} nodes, and therefore have no dynamic semantics.

\ExampleDef{Global Pragma Declarations}
The specification in \listingref{GlobalPragma} contains two global pragmas,
which are ignored by the dynamic semantics.
\ASLListing{Global pragmas}{GlobalPragma}{\definitiontests/GlobalPragma.asl}

\ConventionDef{PragmaNaming}

To avoid conflicts between different ASL parsers, it is recommended that the pragma's identifier $\Tidentifier(\id)$ be prefixed by the name of the ASL tool that supports that pragma
(e.g. ARM for Arm's internal ASL tools).
For example, the pragmas prefixed with \verb|my_tool| in \listingref{GlobalPragma2} may be intended for a tool named \verb|my_tool|.

\ConventionDef{PragmaWarnings}

An ASL tool that does not recognise a pragma directive may:
\begin{itemize}
  \item Choose whether to warn that the pragma is not recognised.
  \item Choose whether to typecheck the pragma (and report type errors appropriately) before discarding it.
\end{itemize}

For example, a tool processing the specification in \listingref{GlobalPragma2} may recognise \\
\verb|my_tool_pragma1| but not \verb|other_tool_op|, and warn about it.
\ASLListing{Warning of pragmas not recognised by tools}{GlobalPragma2}{\definitiontests/GlobalPragma2.asl}

\FormalRelationsDef[defines the formal relations for global pragma declarations]{Global Pragma Declarations}
\paragraph{Syntax:} Global pragma declarations are grammatically derived from $\Ndecl$.

\paragraph{Abstract Syntax:} Global pragma declarations are derived in the abstract syntax from $\decl$,
    and generated via $\builddecl$ (see \ASTRuleRef{GlobalPragma}).

\paragraph{Typing:} Global pragma declarations are checked by $\checkglobalpragma$ (see \TypingRuleRef{CheckGlobalPragma}).

\paragraph{Semantics:} Since global pragma declarations are discarded after typechecking,
    they have no associated dynamic semantics.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\SyntaxDef[defines the syntax of global pragma declarations]{Global Pragma Declarations}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{flalign*}
\Ndecl  \derives \ & \Tpragma \parsesep \Tidentifier \parsesep \ClistZero{\Nexpr} \parsesep \Tsemicolon&
\end{flalign*}

\ASTRuleDef{GlobalPragma}
\begin{mathpar}
\inferrule[global\_pragma]{
  \buildclist[\Nexpr](\vargs) \astarrow \astversion{\vargs}
}{
  {
  \begin{array}{r}
  \builddecl(\overname{\Ndecl(\Tpragma, \Tidentifier(\id), \namednode{\vargs}{\ClistZero{\Nexpr}}, \Tsemicolon)}{\vparsednode})
  \astarrow \\
    \overname{\left[\DPragma(\id, \astversion{\vargs})\right]}{\vastnode}
  \end{array}
  }
}
\end{mathpar}
